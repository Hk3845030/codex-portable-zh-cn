# 一键 Codex 英文转中文界面

> SkillHub 上架的 SKILL：把英文 AI 编程客户端的 UI 一键换成中文。

## 这是什么

`codex-portable-zh-cn` 是一个 SkillHub 上的 Skill，专门用于把 Codex++ 这类英文 AI 编程客户端的界面文案转换为中文。

仓库托管 SKILL.md 元数据、字典源文件、patch 模板，作为 SkillHub 详情页的"源码身份证"。

## 文件结构

```
codex-portable-zh-cn/
├── SKILL.md
├── README.md
├── LICENSE
├── .gitignore
├── scripts/
└── references/
```

## 一键同步到 SkillHub

1. 在 GitHub 上为这个目录创建一个仓库（公开）
2. 在 SkillHub 个人中心绑定 GitHub 账号
3. 在 SkillHub 详情页选「从 GitHub 导入」
